# Retail Project

Este repositorio contiene la pre-entrega del curso de SQL.

## Ejecución

1. Ejecutar el script para crear la base de datos `retail_project`.
2. Abrir una consulta sobre esa base de datos.
3. Ejecutar el resto del script.

El script crea las tablas, carga datos iniciales y realiza un ejemplo de `UPDATE` y `DELETE`.
